# Distance-Conditioned Physics-Informed Metasurface Synthesis

This repository contains the code accompanying the manuscript:

**"Distance-Conditioned Physics-Informed Synthesis of Quantized Phase Profiles for Programmable Metasurfaces"**

by Stefan N. Jovanovi? and Nenad Jovanovic.

The code implements the distance-conditioned, physics-informed deep learning framework described in the manuscript and can be used to reproduce the main numerical experiments and comparisons with the Gerchberg–Saxton (GS) and Weighted Gerchberg–Saxton (WGS) algorithms.

## Code

The main implementation is provided in:

`metasurface_paper.ipynb`

The notebook includes:

- distance-conditioned U-Net architecture;
- propagation-distance conditioning using an input distance channel and FiLM modulation;
- differentiable Angular Spectrum Method (ASM) propagation;
- quantization-aware phase prediction using a Straight-Through Estimator (STE);
- physics-informed training;
- evaluation on the MNIST dataset;
- Gerchberg–Saxton (GS) and Weighted Gerchberg–Saxton (WGS) baselines;
- calculation of reconstruction quality, diffraction efficiency, and runtime metrics.

## Experimental Configuration

The main simulation parameters used in the manuscript are:

- Operating frequency: 150 GHz
- Wavelength: 2 mm
- Metasurface resolution: 128 × 128 elements
- Element spacing: ?/2
- Propagation distance range: 0.2–1.2 m
- Number of discrete phase states: 8
- Training steps: 5,000
- Batch size: 16
- Optimizer: AdamW
- Initial learning rate: 2 × 10??
- Weight decay: 10??

The loss weights used in the experiments are:

- NPCC: 1.0
- off-target energy: 0.5
- ghost/sidelobe suppression: 0.3
- phase snap regularization: 0.02

## Dataset

The experiments use the publicly available MNIST handwritten digit dataset.

The training split contains 60,000 images. Evaluation is performed on 500 images selected from the MNIST test set using a fixed random seed.

The dataset is downloaded automatically when the notebook is executed.

## Requirements

The code requires Python and the following main packages:

- PyTorch
- torchvision
- NumPy
- Matplotlib

A CUDA-capable GPU is recommended for training but is not required for inspecting or running the implementation.

## Running the Code

Open:

`metasurface_paper.ipynb`

in Jupyter Notebook, JupyterLab, or Google Colab and execute the cells sequentially.

The notebook performs the complete workflow including dataset preparation, neural-network training, electromagnetic propagation, phase quantization, evaluation, and comparison with GS and WGS.

## Reproducibility

Random seeds are fixed in the notebook where required for evaluation.

The reported simulation results can be regenerated by executing the notebook. Small numerical differences may occur depending on the hardware, CUDA version, and PyTorch version.
